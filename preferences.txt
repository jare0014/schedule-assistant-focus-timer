# Project and Section Specific Scheduling Rules
- **Focus Blocks Generation**: 
  - Use the project section names from Todoist (e.g., 'Morning Routine', 'Midday Routine', 'Evening Routine') to define and name separate, dedicated Focus Blocks under "### ⏱️ Focus Blocks".
  - For each project section with active tasks, create a distinct timed Focus Block (e.g., `07:00 - 08:00 Habits: Morning Routine`, `12:00 - 12:30 Habits: Midday Routine`, `18:00 - 19:15 Habits: Evening Routine`).
  - Schedule the corresponding tasks as individual checklist subtasks under their respective Focus Block.
  - Never combine or pile separate project sections into a single task or block.
  - Strip any trailing "(Project: ..., Section: ...)" or "(Project: ...)" context labels from the task names in the final schedule output. Do NOT put bracketed project prefixes in the task names themselves.
